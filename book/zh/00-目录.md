## 第 1 章　编程代理是怎么工作的

- **学习目标：** 说清大模型、代理框架（harness）和工具的关系；能自己写出「循环 + 工具」的最小代理；理解为什么上下文决定代码质量。
- **对应课程：** 9/22 课程介绍 + 200 行 Claude Code；9/24 现代编程代理解剖；阅读 Building a Coding Agent、Lessons from Building Claude Code、Dive into Claude Code。
- **练习：** 作业 1，抓包观察一个真实编程代理的请求。

## 第 2 章　上下文工程与规格驱动开发

- **学习目标：** 掌握进阶提示词写法；理解上下文窗口的成本和压缩时机；学会先写规格、再让代理实现（RePPIT 等框架）。
- **对应课程：** 9/29 进阶提示词 + 代理开发框架；阅读 The Context Tax、OpenSpec、Superpowers。

## 第 3 章　工具与能力：MCP 和 Skills

- **学习目标：** 理解工具调用和 MCP 协议；会写 skill；知道何时用 MCP、何时用 skill、何时直接用命令行。
- **对应课程：** 10/1 MCP 与工具调用；10/6 Agent Skills 全解；阅读 Enterprise MCP、pstack、Matt Pocock's Skills、browse.sh。
- **嘉宾专栏：** Lee Robinson（10/8）。课件标注保密，只写公开可得的要点。

## 第 4 章　定制你的代理

- **学习目标：** 写好 CLAUDE.md / AGENTS.md；会用 hooks、规则和子代理约束代理行为。
- **对应课程：** 10/13 定制代理配置；阅读 I Still Prefer MCP Over Skills、AGENTS.md、Steering Claude Code、Writing a Good CLAUDE.md。
- **嘉宾专栏：** Boris Cherny（10/15，Claude Code）。待官方材料。

## 第 5 章　让代码库适合代理

- **学习目标：** 从结构、文档、测试和检查几方面评估代码库的「代理就绪度」，并动手改进。
- **对应课程：** 10/20 代码库的代理就绪度；阅读 Making Codebases Agent Ready、Making Ergonomic Repositories。
- **嘉宾专栏：** Eno Reyes（10/22，Factory）。可参考访谈视频 <https://youtu.be/pHGGlrKSnJ8>。
